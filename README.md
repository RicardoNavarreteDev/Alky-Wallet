# ALKY WALLET

## Descripción
ALKY WALLET es una billetera digital básica desarrollada como proyecto educativo. Permite iniciar sesión, consultar el saldo disponible, realizar depósitos, enviar dinero a contactos y revisar los últimos movimientos de la cuenta.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- Local Storage
- Font Awesome

## Principales funcionalidades
- Inicio de sesión con validación de credenciales.
- Menú principal con acceso a las distintas pantallas.
- Depósito de dinero con actualización del saldo.
- Envío de dinero a contactos guardados.
- Alta y búsqueda de contactos.
- Consulta de últimos movimientos con filtro por tipo de operación.
- Persistencia de datos usando Local Storage.
